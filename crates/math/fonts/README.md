# New Computer Modern Math

`NewCMMath-Regular.otf` is New Computer Modern Math by Antonis Tsolomitis,
unmodified, as Typst ships it (`typst-assets` 0.15.1, `files/fonts/`;
SHA-256 `d66ac1cc91c55c24d3636ae2df1238076debdff51841f9893fc5419cc2df3df7`).
It is Typst's default math font and the only font the math worker has.

It is licensed under the GUST Font License 1.0 (`GUST-FONT-LICENSE.txt`):
the LaTeX Project Public License 1.3c or later, with the request (not a
requirement) that modified versions be renamed. The math worker embeds it
unmodified. The text faces of New Computer Modern are not used: NewCM10-Regular
is GPL-3.0-or-later with a font exception, the other faces are GUST like this
one, and the math font has upright Latin letters for `\text` already.
